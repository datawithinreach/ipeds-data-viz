# Finding Sources in IPEDS

## Goal

Analyze educational data across U.S. universities to create articles with interactive visualizations.

## Step-by-Step Workflow

1. Open the IPEDS Data Center institution comparison page:  
   [IPEDS Data Center - Compare Institutions](https://nces.ed.gov/ipeds/datacenter/InstitutionByName.aspx?goToReportId=1&sid=1ae89e87-27cb-4502-b92d-40a8203f5151&rtid=1)

2. Gather each institution's Unit ID before comparing schools. Use this mapping source:  
   [College and University Unit ID Mapping (PDF)](https://secondnature.org/wp-content/uploads/Workbookv7-Sheet1.pdf)

   Note: You can use institution names directly, but Unit IDs are much easier when comparing multiple universities at once.

3. In IPEDS, enter the Unit IDs as a comma-separated list.
   
   ![Step 3: Enter Unit IDs in IPEDS](/step-3.png)

4. Click **Select All**, then click **Continue**.
   
   ![Step 4: Select all institutions and continue](/step-4.png)

5. At the top of the page, select **2. Select Variables**.
   
   ![Step 5: Open the Select Variables tab](/step-5.png)

6. Expand categories and choose the variables you want to analyze.  
   After making your selections, click **Continue**.
   
   ![Step 6: Choose variables and continue](/step-6.png)

7. Click **Continue** again to generate and download the CSV.
   
   ![Step 7: Generate and download the CSV](/step-7.png)

## Tips

- Start with a small set of institutions to validate your workflow.
- Keep a reusable list of frequently used Unit IDs for faster comparisons.
- Export only variables needed for your visualization to keep CSV files manageable.
